How it works

Once deployed to GitHub Pages, your site serves a fresh vocabulary wallpaper at its URL. The page auto-selects a term based on the current hour of the day — so every hour Shortcuts visits the URL, it gets a different wallpaper image.

The words.json file holds all your vocabulary pairs. The page renders the wallpaper as a canvas element and the Shortcut uses Take Screenshot or Get Contents of URL + Set Wallpaper.

1 — Deploy to GitHub Pages

  1. Create a new repository on github.com (e.g. my-wordwall).
  2. Upload this index.html file and the words.json file you download below into the repo root.
  3. Go to Settings → Pages, set source to branch main, folder / (root) and save.
  4. After a minute your site will be live at https://YOUR-USERNAME.github.io/my-wordwall/

2 — Create the Shortcut

  1. Open the Shortcuts app on your iPhone.
  2. Tap + to create a new Shortcut.
  3. Add action "Get Contents of URL" and paste your GitHub Pages URL (the root / page).
  4. Add action "Take Screenshot" — or if the previous step returns an image directly, skip this.
  5. Add action "Set Wallpaper" — choose Lock Screen, Home Screen, or both. Use the result of the previous step as the image.
  6. Tap the shortcut name at the top → Add to Automation.
  7. Choose "Time of Day" → set it to repeat every 1 hour starting 12:00 AM.
  8. Disable "Ask Before Running" so it runs silently in the background.
Tip: For the cleanest result, use Get Contents of URL pointing to your GitHub Pages URL. The page will render and your Shortcut can take a screenshot, then set it as wallpaper. Alternatively, download the PNG manually each time using the Download button above and set it via Photos.

3 — Download words.json for your repo

After uploading your PDF and reviewing the entries, download this file and commit it to your GitHub repo alongside index.html. The page will auto-load it on every visit.
